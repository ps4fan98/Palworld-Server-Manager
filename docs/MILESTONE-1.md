- [ ] Manager starts at `http://127.0.0.1:8213`

- [ ] Force-stop requires confirmation
- [ ] Start and force-stop operations create audit records
- [ ] Windows service installs and starts
- [ ] Manager remains unreachable from another LAN computer
- [ ] No firewall rule is created by this milestone
